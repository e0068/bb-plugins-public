# @bb-plugins/shapeshift-link-icons

Вендоренная копия файла стилей значков ссылок дизайн-системы [Shapeshift](https://github.com/e0068/Shapeshift) (`src/2-functions/link-icons.css`): значок у любого элемента с `data-href` по адресу ссылки. У ссылки на файл — значок формата перед текстом, у http(s) — квадрат со стрелкой после текста, у mailto — конверт, у якоря `#…` — ничего; элемент с классом `mde-link-plain` (ссылка без обработчика) значка не получает. Подчёркивание — только при наведении.

Таблица «адрес → значок» живёт в Shapeshift и только там ([решение](../../docs/decisions/link-icons-live-in-design-system.md)). Новый формат или другой значок — правка в Shapeshift, затем обновление копии.

## Правила

- **`vendor/` руками не правится.** Копию кладёт `npm run update` (по умолчанию — `main` чекаута `~/Documents/Projects/Shapeshift`; `-- --from <чекаут> --ref <коммит>` — другой). Файл берётся из git по коммиту, а не с диска, поэтому коммит в `vendor/manifest.json` всегда описывает копию. Тест `vendor-integrity.test.ts` сверяет копию с манифестом и держит её самодостаточной.
- Подключает стили [packages/md-doc-view](../md-doc-view): `MdDocView.tsx` импортирует `vendor/link-icons.css` после стилей движка Kasimov — правило подчёркивания при наведении весит столько же, сколько класс `.mde-link`, который подчёркивание снимает.
