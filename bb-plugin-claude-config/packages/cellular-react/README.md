# @bb-plugins/cellular-react

Компоненты kit Cellular внутри React-плагинов bb, покрашенные токенами темы bb.

## Что здесь

| Файл | Что |
|---|---|
| `Kit.tsx` | монтажник: `<Kit make={button} props={{ label: "Count", onClick }} />` создаёт элемент фабрикой kit и держит его в согласии с пропсами: колбэки и объекты (`menu`, `num`) всегда свежие через мешок `props-bag.ts`; при смене значений элемент с `_refresh` (кнопка, числовое поле) перечитывает пропсы, без `_refresh` (сегмент, переключатель, текстовое поле) пересоздаётся; при размонтировании снимает фокус со своего элемента (закрывает меню поля) и изображает клик снаружи (закрывает меню кнопки) |
| `props-bag.ts` | чистое: мешок пропсов фабрики — трамплины для функций, живые представления для объектов, подпись значений |
| `bb-tokens.css` | мост: все themed-каналы `--cell-*` и общие `--cl-kit-*` kit получают значения из токенов bb (`--muted`, `--foreground`, `--primary`, `--radius`, …), литеральных цветов нет |
| `styles.css` | единая точка подключения: `components.css` kit, затем мост — порядок обязателен, `:root` kit иначе перекрывает мост |
| `index.ts` | `Kit` и реэкспорт фасада `cellular-kit` |

## Как пользоваться из плагина

```tsx
import { Kit, button, segment } from "../packages/cellular-react";
import "../packages/cellular-react/styles.css";

<Kit make={button} props={{ label: "Count", onClick: count }} />
<Kit make={segment} props={{ items: [{ label: "Плашки" }, { label: "Линии" }], value: 0, onSelect: setGrid }} />
```

Массовую разметку (ячейки виртуализированной сетки) через `Kit` не монтируют: сотни эффектов на экран. Там пишется JSX с классами kit (`uicell`, `clab`, `cval`) поверх того же `styles.css`.

## Ограничения

- Меню kit висит на `document.body` и не отдаёт ручку наружу. Меню поля закрывается точечно снятием фокуса; меню кнопки — только «кликом снаружи» на документе, который закрывает все открытые меню kit и слои Radix. Событие шлётся лишь при размонтировании и лишь при открытом меню kit; пересоздание элемента в документ ничего не шлёт.
- Фабрики без `_refresh` пересоздают элемент при смене значений: набранный текст в поле пропадёт, если у него сменится `placeholder`; сегмент и переключатель внутреннего состояния не держат. Разбор — [docs/decisions/cellular-kit-wrapper-not-port.md](../../docs/decisions/cellular-kit-wrapper-not-port.md).
