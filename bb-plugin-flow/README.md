# Flow

Агент спрашивает владельца не прозой, а брифом в ленте треда: одно окно со всеми вопросами, у каждого варианта развилки — что произойдёт, примерная цена и риски, рекомендация агента помечена, к развилке всегда можно ответить своё. Ответ уходит агенту одной репликой, а бриф остаётся в истории с отмеченным выбором.

## Что внутри

- Инструмент агента `ask_decision` и навык `flow`: любой вопрос, уточнение, развилка и непонимание идут через них.
- Директива `::decision{id="dec_…"}` — на её месте в сообщении агента рисуется бриф.
- Вопросы второй части: `fork` (развилка с описанием и добавкой), `pick` (несколько ответов), `confirm` («правильно ли я понял»), в уточнении — `yesno`.
- Страница Flow в левом меню bb: несколько flow, у каждого своя таблица этапов с перетаскиванием. Этап — навык с названием и исполнителями (агенты и workflow) или встроенный вид: Вопросы, Критерии, Выбор этапов, Демонстрация; встроенные виды ставятся сколько угодно раз пятью кнопками под таблицей. Работа встроенного этапа — в его навыке: по умолчанию `flow-questions`, `flow-criteria`, `flow-stage-selection`, `flow-demo`, в таблице встроенному этапу ставится любой. Навыки лежат в `~/.claude/skills` (или в `.claude/skills` репозитория) и работают и в обычном Claude Code — там вопросы идут через AskUserQuestion. Над таблицей — ссылка на корневой навык `flow`, через который агент выбирает flow, когда тред не идёт по flow. Минимальная ширина кнопки этапа — общая. В брифе части подписаны бирками вида; по кнопке на этап: взять ли его в ближайший прогон, кто исполняет и сколько это стоит, ссылки на сделанное — пройденный этап не снять.
- Демонстрация: на этапе Демонстрация агент кратко показывает всё сделанное с прошлой демонстрации со ссылками; владелец продолжает, продолжает с комментарием или отправляет на доработку. Если менялся код, в Демонстрации есть живой результат: страница поднятого сервера (через `bb connect expose`, без Connect — localhost) или команда запуска десктопного приложения — блок команды с кнопкой «Выполнить в терминале». Без живого результата инструмент итог не примет, если агент не отметил, что менялись только документы. Слева от кнопок Демонстрации, как и у любой отправки брифа, — «Исполнять».
- Прогресс flow над композером треда: «N из M», сегменты этапов и план; тап раскрывает этапы с потраченным временем, деньгами и ссылками. Агент отмечает этапы инструментом `flow_stage`. Значок этапа, на котором идёт работа — ход агента или прогон автоматизации, — приглушённо мерцает; у этапа самого агента значок — логотип провайдера треда, у субагента — маленький логотип его провайдера в квадрате, так же и у исполнителя-агента в брифе и настройках; простой агента на этапе не мерцает; поверх сегмента идущей автоматизации мерцает молния, под её строкой — шаги, у упавшего — ошибка, «Повторить» и «Пропустить».
- Значок в левой панели: тред, который ждёт владельца на Вопросах, Критериях, Выборе этапов или Демонстрации, показывает значок этого этапа; тред, где сейчас идёт работа, — приглушённо мерцающий значок этапа (логотип провайдера исполнителя, у субагента — в квадрате): этап навыка — только пока агент работает, автоматизация — пока идёт прогон; упавшая автоматизация — ровная молния в тоне ошибки.
- Автоматизации: кнопка «Автоматизация» ставит встроенную автоматизацию Flow — шаги тегами (Commit, подтянуть ветку к main, открыть PR, задача → in_review, Bump major, Bump minor, Bump patch, смёрджить PR, подтянуть main, обновить плагины с гита, задача → done, архивировать тред; тег бампа ставится между открытием PR и мёрджем, обновление плагинов — после мёрджа), их можно добавить, убрать и переставить. «Добавить скрипт…» в том же меню берёт файл: его содержимое хранится в автоматизации, а шаг называется именем файла; Flow запускает скрипт в рабочем дереве треда — с shebang своим интерпретатором, без него через sh, с `BB_THREAD_ID` и `BB_ENVIRONMENT_ID`; ненулевой код выхода или 10 минут без завершения — шаг упал, в ошибке хвост вывода; запущенное скриптом в фоне шаг не держит, а по таймауту останавливается вместе со скриптом; набор шагов встроенной автоматизации сохраняется кнопкой-закладкой у её строки: сохранённые наборы без имени стоят сверху меню кнопки «Автоматизация» строкой своих шагов и ставятся в новый этап одним выбором, крест убирает набор; «Из плагина Automations» ставит включённую автоматизацию Automations, её шаги видны только для чтения. Автоматизации исполняет сам Flow, без агента: когда агент отметил этап перед ними, Flow выполняет подряд стоящие автоматизации и агенту ничего не шлёт; упавший шаг останавливает цепочку и ждёт владельца. Код шагов — общий с Automations пакет [packages/automation-steps](../packages/automation-steps), так что встроенные автоматизации работают и без Automations. Flow сообщает Automations о своих событиях — итог этапа, ответ на бриф, утверждённые критерии, — и автоматизации с этими триггерами срабатывают; связь идёт по HTTP через [packages/automations-contract](../packages/automations-contract).
- Инструменты агента `read_flows` и `save_flow`: агент читает flow с каталогом навыков, исполнителей и шагов автоматизаций и сохраняет один flow — новый или на замену, на нужное место в списке. Этап с навыком или исполнителем не из каталога и шаг-скрипт без скрипта отклоняются, при отказе ничего не сохраняется; открытая страница Flow показывает сохранённое сразу. Из чего собирать flow, как подключать шаги Flow, свои скрипты и автоматизации Automations — навык `flow-create` в `~/.claude/skills`.
- Кнопка flow в композере нового треда рядом с выбором модели: тред идёт по выбранному flow — из него этапы в инструкциях агенту и в проверке брифа. Треды без выбора идут по первому flow в списке.
- Журнал решений: секция настроек «Директория журнала решений» — путь по проекту, от корня рабочего дерева треда. Каждый ответ на бриф (не на уточнение) кладётся туда файлом — решение едет вместе с веткой и попадает в тот же PR, что и код, ради которого его приняли. Нет пути или у треда нет рабочего дерева — журнал молча не ведётся, ответу и реплике агенту это не мешает.

- Язык: настройка Language — System (язык браузера), English или Русский; на нём интерфейс, страница Flow и ответ в тред. Навык и инструкции агенту — на английском.

## Установка

```bash
cd bb-plugin-flow && npm install && bb plugin install "path:$PWD" --yes
```

Инструмент появляется в тредах, начатых после установки.

## Разработка

`npm test` — тесты, `npm run typecheck` — типы, `bb plugin build` — сборка бандла. Устройство и стыки — [docs/architecture/bb-plugin-flow.md](../docs/architecture/bb-plugin-flow.md).
