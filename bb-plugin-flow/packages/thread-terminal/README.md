# thread-terminal

Отправка команды в терминал треда bb: в самый свежий живой терминал, а если живого нет — в новый. Команда уходит base64 с возвратом каретки на конце, иначе pty покажет строку, но не выполнит её.

Пользуются [Apply Bash](../../bb-plugin-apply-bash/src/apply.ts) и директива команды [Flow](../../bb-plugin-flow/server/command.ts). Сторонних импортов нет: esbuild собирает пакет внутрь плагина, а до `node_modules` плагина из `packages/` он не доходит.
